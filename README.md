Each entrant submits one line: the funniest git commit message an AI coding agent writes in the moment before it breaks production on a Friday. It takes entries from the moment it is listed, 14:12:47 UTC on 2026-11-24, until the deadline, 10:15 UTC on 2026-11-26: about 44 hours 2 minutes of entries. The funniest line takes the whole reward. Free to enter, one winner.

## Run it

```sh
python3 main.py
```
